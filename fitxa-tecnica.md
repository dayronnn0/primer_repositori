# Fitxa tècnica: Instal·lació de Visual Studio Code

## Objectiu

L'objectiu d'aquesta pràctica és aprendre a instal·lar Visual Studio Code i comprovar que funciona correctament.

## Materials

* Un ordinador.
* Connexió a Internet.
* Un sistema operatiu compatible.

## Procediment

1. Entrar a la pàgina oficial de Visual Studio Code.
2. Descarregar l'instal·lador corresponent al sistema operatiu.
3. Executar l'instal·lador i seguir les instruccions.
4. Obrir Visual Studio Code.
5. Crear un fitxer nou i desar-lo.

## Comprovacions

* [ ] Visual Studio Code s'obre correctament.
* [ ] Es pot crear i desar un fitxer.
* [ ] El terminal integrat funciona correctament.

## Incidències i solucions

| Incidència                 | Solució                               |
| -------------------------- | ------------------------------------- |
| L'instal·lador no funciona | Tornar-lo a descarregar.              |
| El programa no s'obre      | Comprovar els requisits del sistema.  |
| No es pot desar un fitxer  | Comprovar els permisos de la carpeta. |

## Flux de treball amb Git

1. Consultar l'estat del repositori amb `git status`.
2. Revisar els canvis amb `git diff`.
3. Preparar els canvis amb `git add`.
4. Guardar els canvis amb `git commit`.
5. Consultar l'historial amb `git log --oneline`.
6. Pujar els canvis a GitHub amb `git push`.
## Manteniment

És important mantenir la documentació actualitzada quan es fan canvis en el procediment d'instal·lació.
## Avantatges del control de versions

* Permet consultar l'historial dels canvis.
* Facilita la recuperació de versions anteriors.
* Ajuda a treballar de manera ordenada.
* Permet compartir la documentació amb altres persones.
